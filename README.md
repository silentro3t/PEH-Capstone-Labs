## How to use

1. Download the lab(s) you need from the MEGA link above. You don't have to download everything.
2. Extract the `.7z` file:
   - Windows: use [7-Zip](https://www.7-zip.org/), right click → **Extract here**
   - Linux: `7z x Dev.7z`
3. Open or import the VM in VMware or VirtualBox.
4. Start the VM and connect it to the same network as your attack machine (e.g. Kali Linux).

## Requirements

- VMware Workstation / Player **or** VirtualBox
- Kali Linux (or another pentesting VM)
- At least 8 GB RAM (16 GB recommended)
- Enough free disk space for the extracted VMs

These labs are for **educational and legal practice only**. Run them only in your own isolated environment, never against real networks or systems you don't own. Please check the licensing and terms of the original course material before sharing.
